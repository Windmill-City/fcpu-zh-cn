# fCPU 简体中文补丁

fCPU 提供一个程控运算器，能够使用简单汇编语言处理游戏内信号

- 原项目（fCPU）：<https://mods.factorio.com/mod/fcpu>

## 内容

- 完整汉化 fCPU 的界面文本与提示
- 让 Informatron 游戏内维基显示简体中文内容
- 可选：把程控运算器的占地面积从 2x2 改为 2x1（启动设置「紧凑尺寸」）
- 独立模组，不影响 fCPU 本体，可随时卸载

## 安装

在模组设置中启用本模组即可，无需额外配置。自动覆盖原版英文文本。

需要调整程控运算器尺寸时，在模组设置的「启动」分类中打开「紧凑尺寸（2x1）」后重启游戏。

## 兼容性

- 需要 fCPU >= 0.4.65 与 base >= 2.0
- 仅支持 Factorio 2.0 及以上版本

## 编译

本地打包并自动复制到 Factorio mods 目录：

```powershell
.\build.ps1
```
