# fCPU

## Спецификация

* поддерживает чертежи
* поддерживает копирование и вставку
* поддерживает мультиплеер
* поддерживает внутри-игровую документацию [Informatron](https://mods.factorio.com/mod/informatron) и [Booktorio](https://mods.factorio.com/mod/Booktorio)
* 256 инструкции для всей программы
* 8 регистров общего назначения
* 50+ операций
* богатые математические инструкции
* два входных провода (красный, зеленый)
* два выходных провода (красный, зеленый) имеют одинаковые выходные сигналы и значения
* параллельный выход, позволяет выводить несколько сигналов одновременно (до 256 сигналов)
* может управляться через специальные входные сигналы
* один игровой кадр (тик) = одна инструкция
* сделано для гиков



## Описание
fCPU это комбинатор, включающий в себя:

- текст программы  
- набор регистров (для хранения сигналов и чисел)  
- процессор (обработчик команд)  


### Программа
Программы для fCPU вводится обычным текстом на упрощенном [языке ассемблера][1] и состоит из строк.
Каждая строка представляет собой одну инструкцию.
Инструкция состоит из мнемоники и операндов.  
Например: `mov out1 123[item=copper-ore]`, тут `mov` это мнемоника, `out1` первый операнд, `123[item=copper-ore]` второй операнд.
Эта инструкция указывает процессору отправить сигнал `[item=copper-ore]` со значением `123` на провода, подключенные к выходу.

Мнемоника это сокращенные названия операций, которые понимает и умеет исполнять процессор.  
Операнды это аргументы операций. Они используются, чтобы указать значения над которыми будет выполнена операция.

В качестве операндов могут использоваться:

- Сигналы: каждый сигнал состоит из типа и значения (`123[item=copper-ore]`)
  `123` - значение сигнала представленно числом
  `[item=copper-ore]` - тип может быть предствален пиктограммой или текстом
- Регистры: это специальные ячейки, хранящие переданные сигнал неограниченно долго (`reg1`, `r2`, ...)
- Входы: можно получить сигналы на проводах, подключенных ко входу fCPU комбинатора (`red`, `green`)
- Выходы: устанавливает значения на выходе fCPU комбинатора (`out1`, `out2`, ..., `out256`)
- Адрес: адрес инструкции (номер строки)
- Метка в коде: записываектся текстом с двоеточием впереди (`:label`, `:anyname`, ...)

Процессор выполняет инструкции из написанной программы по очереди - строка за строкой.  


[1]: для быстрого изучения достаточно этого руководства


### Регистры

Существует 8 регистров общего назначения для чтения/записи с именами **reg1**, ... **reg8** (или **r1**, ... **r8**).
Каждый регистр хранит тип сигнала и числовое значение (поддерживаются числа с плавающей запятой).
Например, `mov reg2 10[item=iron-plate]`, эта инструкция присваивает **reg2** значение *10* и тип *[item=iron-plate]*.

Помимо регистров общего назначения есть несколько регистров только для чтения:

- **ipt**: номер строки текущей инструкции
- **clk**: часы, значени увеличивается с каждым тиком
- **cnr**, **cng**: кол-во сигналов на красном `cnr` или зеленом `cng` входном проводе

Регистры вывода возможна только запись:

- **out1**, ..., **out256**: регистры вывода (только целые значения)
